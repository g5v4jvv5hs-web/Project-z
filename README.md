# Project Z — Backend Starter

This is the first programming skeleton for Project Z.

## Current
- Express backend
- User creation
- Balance
- Live total-pool endpoint
- TEST entry endpoint using simulated credits
- No real-money payment
- No winner selection

## Run
1. Install Node.js.
2. Open this folder in Terminal.
3. Run `npm install`
4. Run `npm start`
5. Backend runs on `http://localhost:3000`
